The shortcuts below are active whenever a wallet is open. On macOS, read Ctrl as the Command key.

#### Everyday

| Shortcut | Action |
|----------|--------|
| Ctrl + O | Open wallet |
| Ctrl + N | New or restore wallet |
| Ctrl + W | Close wallet |
| Ctrl + F | Toggle the searchbar |
| Ctrl + D | Show debug info |
| Ctrl + Alt + S | Open settings |

#### Less common

| Shortcut | Action |
|----------|--------|
| Ctrl + U | Update balance |
| Ctrl + S | Save the wallet. Saving already happens on its own, so this is rarely needed. |
| Ctrl + R | Refresh the internal models. **Warning:** a known bug means this **can** crash the wallet if you press it while [synchronization](synchronization) is running. |
