Stagenet and testnet are separate Monero networks meant for experimentation. Coins on either one have no value whatsoever — never accept them as payment for anything real.

**Switching networks**

Launch the wallet with `--stagenet` or `--testnet` on the command line. The network is fixed for the lifetime of the process; there is no switch inside the interface.

### Getting test coins

A faucet will send you stagenet coins for free:

**Stagenet**: [https://stagenet-faucet.xmr-tw.org/](https://stagenet-faucet.xmr-tw.org/)

No testnet faucet is currently known. The Monero project keeps a broader list of network resources [here](https://docs.getmonero.org/infrastructure/networks/).
