title: Troubleshooting startup issues
nav_title: Startup issues
category: troubleshooting
---

When the wallet refuses to start, run it from a terminal. Errors that a double-click would swallow get printed there, and that output is what makes a bug [report](report-an-issue) actionable.

### Linux

Drag the BestWallet binary into a terminal window and press enter.

### Tails

Open **Applications → System Tools → Terminal**, then drag the BestWallet AppImage from the file manager into the terminal and press enter.

### Windows

Press **Windows key + R**, type `cmd.exe`, and confirm. In the command prompt that opens, drag the BestWallet executable in from Explorer and press enter.

### macOS

Launch BestWallet from a terminal.

---

Whatever the platform, copy the messages the wallet prints and include them when you [report the issue](report-an-issue).
