Bugs, questions and feature requests all belong in the issue tracker:

**[github.com/BestWalletTeam/BestWalletApp/issues](https://github.com/BestWalletTeam/BestWalletApp/issues)**

**Before you open one**

Copy the contents of **Help → Debug Info** into the report. It records your version, platform, node and sync state, which is usually enough to tell an environment problem from a real bug.

If the wallet fails to start at all, the console output described in [Startup issues](troubleshooting-startup-issues) is the single most useful thing you can attach.

**Security vulnerabilities**

Do not use the public tracker. Follow the disclosure process in the project's `SECURITY.md` instead, so the problem can be fixed before it is described in public.

**A note on impersonation**

BestWallet is developed in the open, in one place: the GitHub repository linked above. There is no official chat channel, no support email and no download site — anything presenting itself as one is not connected to this project. Build from source, or use the release artifacts attached to that repository.
