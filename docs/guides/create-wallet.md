Open the wizard with **File → New/Restore** if it isn't already showing, and choose **Create new wallet**.

### 1. Write down the seed

The wizard shows your seed next. It is 16 words rather than the 25 you may have seen elsewhere — BestWallet uses Polyseed, and [Seed scheme](seed-scheme) explains what that buys you.

This is the only thing that can bring your money back if the wallet files are lost. Copy it onto paper and store the paper somewhere safe. Do not put it in a file on your computer, and do not send it anywhere.

Move on only once you have checked every word, in order, against what is on screen.

### 2. Name it and choose where it lives

**Name** can be anything; a name that isn't taken yet is suggested for you.

**Directory** is where the wallet files land. The default is the right answer for almost everyone. If you would rather keep everything beside the executable — on a USB stick, say — set up [portable mode](portable-mode) instead of changing this.

### 3. Set a password

The password encrypts the wallet files on disk. Generate a strong one with a password manager such as [KeePassXC](https://keepassxc.org/).

Click **Create/Open wallet** and the wallet is ready.
