When a transaction that should belong to your wallet never appears, you can pull it in by hand using its transaction ID.

Let the wallet finish [synchronizing](synchronization) first — importing against a partially scanned wallet tends to be wasted effort.

**Steps**

1. Go to **Tools → Import Transaction**.
2. Paste the transaction ID.
3. Click **Import**.

If the transaction is really yours, it will surface in the **History** tab. Should the import report success while the entry still seems absent, check that you are looking at the right [account](accounts) — history is shown per account.
