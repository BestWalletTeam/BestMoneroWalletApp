The address checker answers three questions about any address you paste into it:

- Is this a well-formed Monero address?
- Does it belong to the wallet that is currently open?
- If it does, which [account](accounts) does it sit under?

Open it from **Tools → Address Checker**.

This is handy before sending a large amount, or when you want to confirm that an address someone quoted back to you really is one of yours.
