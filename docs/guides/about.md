BestWallet is a desktop Monero wallet built in C++ on the Qt framework. It builds on the Monero project's wallet code and on a number of other open-source projects, listed in full in the project's third-party licence notices.

The source is free and open, released under the BSD-3-Clause licence, and lives at [github.com/BestWalletTeam/BestWalletApp](https://github.com/BestWalletTeam/BestWalletApp).

### What it aims to be

- **Light on its feet.** Small, quick, and comfortable on ordinary hardware — including virtual machines and live systems.
- **Approachable without being limited.** Someone opening a Monero wallet for the first time should manage fine, while an experienced user should not have to fall back to the CLI to get something done.
- **Sensible by default, adjustable when needed.** The out-of-the-box configuration suits most people; the settings are there for those with unusual or demanding threat models.
- **Willing to try things.** New ideas can be tested here more readily than in the reference wallets.

### Contributing
