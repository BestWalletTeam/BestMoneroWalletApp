---
title: How to use the webcam QR code scanner
nav_title: Use webcam QR code scanner
category: howto
---

Click **Scan** on the **Send** page to open the scanner. If more than one camera is attached, pick the one you want from the combobox along the bottom.

Hold the code up to the lens. The dialog closes by itself the moment it reads successfully, and the **Send** tab fills in with whatever the code contained.

**If it won't read**

- Get the whole code inside the frame
- Check the orientation
- Angle the code away from any light that is reflecting off it
- Dim the screen displaying the code — an over-bright image scans poorly

### The viewfinder stays black

Check for a privacy shutter or sticker over the lens first. If the camera is uncovered and the picture is still black, [report](report-an-issue) it and mention your webcam model and operating system.

### No cameras are listed

Reboot, and reseat the USB cable if it is an external camera. Check whether any other application can see it. If nothing explains it, [report](report-an-issue) the problem with your webcam model and operating system.

### "Built without webcam QR scanner support"

Scanner support is compiled into every official build. Seeing this message means you are running a build from somewhere else — ask whoever packages it to enable the scanner.
