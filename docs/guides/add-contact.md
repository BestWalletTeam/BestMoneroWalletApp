title: How to add a contact
nav_title: Add a contact
category: howto
---

Contacts give recurring addresses a readable name so you don't have to re-check a long string every time you pay someone.

**Adding one**

1. Switch the tab on under **View → Contacts** if it isn't already showing.
2. Open the **Contacts** tab.
3. Right-click anywhere in the table and choose **New contact**.
4. Fill in the address and a name, then confirm with **Ok**.

Adding an address that is already stored does not create a duplicate — the existing entry simply takes on the new label.

**Paying a contact**

Right-click the contact and choose **Pay to**. The address drops into the **Pay to** field and the contact's name is copied into **Description** for you.
